Snake

A small Snake game for Windows. Control the snake, collect food, unlock new skins, try to achieve the highest possible score, and complete your Collector’s Book.

Download and Installation

1. Open the **Releases** section of this project.
2. Download the file **Snake.Setup.1.0.0.exe**.
3. Open the downloaded file and follow the installation steps.
4. Launch Snake using the shortcut in the Start menu or on your desktop (if one was created).

Controls

Movement = W, A, S, D; Arrow keys
